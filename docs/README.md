# Tài liệu dự án

Thư mục chứa tài liệu phân tích, thiết kế và vận hành của Mini Apartment Management.

| Tài liệu | Trạng thái |
| --- | --- |
| Đặc tả yêu cầu & vai trò người dùng | Chưa có |
| Thiết kế cơ sở dữ liệu (≈ 20 bảng) | **Đang chờ duyệt** — chưa tạo migration nghiệp vụ |
| Đặc tả REST API `/api/v1` | Chưa có — hiện chỉ có `GET /api/v1/health` |

Khi thiết kế CSDL được duyệt, lưu tại `docs/database/` (ERD + mô tả bảng) trước khi viết migration.
